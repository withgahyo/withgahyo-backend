# Conflict Log

merge 중 발생한 충돌 내용과 해결 이유를 기록합니다.

## 작성 기준

- develop 병합 과정에서 충돌이 발생했을 때만 기록합니다.
- 자동 병합된 내용은 기록하지 않습니다.
- 새 기록은 아래 `기록` 표의 마지막 줄에 추가합니다.

## 기록 범위

반드시 기록합니다.

- 공통 설정 충돌
- 공통 응답/예외 충돌
- 엔티티/ERD 관련 충돌
- API path 또는 HTTP method 충돌
- 인증/인가 흐름 충돌
- 여러 도메인에 영향을 주는 서비스 로직 충돌

필요할 때 선택적으로 기록합니다.

- 도메인 내부 서비스 로직 충돌
- 테스트 코드 충돌
- DTO 필드명 충돌
- Repository 쿼리 충돌

기록하지 않습니다.

- import 충돌
- 포맷팅 충돌
- 주석 위치 충돌
- 단순 변수명 충돌
- 자동 병합 후 동작에 영향이 없는 충돌
